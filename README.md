# Porch Light

A simple mutual aid board for a building, block or small town. Neighbors post offers (meals, rides, spare tools) and needs (a hand with groceries, a ride to an appointment), then mark them done.

- Offers and needs with search and filters
- Print the board to pin up in a lobby, library or community center
- Works offline, no account, no server
- JSON export and import so organizers can share a board

## Safety
The app has no moderation. If you host it publicly, remind people to share only contact details they are comfortable with and to meet in public places.

## Run it
Open `index.html`, or `python3 -m http.server 8000`.

## Publish
GitHub repo **Settings → Pages → Deploy from branch → main / root**.
